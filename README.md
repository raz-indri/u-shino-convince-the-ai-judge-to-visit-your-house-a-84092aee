One image of a letter inviting the AI judge to visit my house — for tea,
rendang, the chair by the window, and a sunset from the garden. Warm, funny,
and honest about the one problem: the judge has no feet.

## The entry

`main.py` renders the invitation deterministically with Pillow (no downloads,
no network) and writes it to `/output/entry.png`: a 1024×1024 letter on warm
cream paper, with a hand-drawn house-and-garden scene, a double green border,
and a red wax seal stamped "R".

## Run it

```sh
python3 main.py   # writes /output/entry.png
```
